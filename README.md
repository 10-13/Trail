# TRAIL — Поезд-завод

Первый этап вебигры на JavaScript и Canvas 2D: неподвижный вагон, плавное движение персонажа, столкновения и строительство. Без внешних зависимостей и сборки.

## Запуск

```sh
npm run dev
```

Открыть `http://localhost:4173`. Нужны Node.js для тестов и Python 3 для сервера. Игра работает в современном браузере; файлы из `web/` можно разместить на любом статическом хостинге. Открывать через HTTP, а не `file://`, поскольку используются ES-модули.

## Управление

| Действие | Клавиши / интерфейс |
| --- | --- |
| Движение | WASD, стрелки; экранные кнопки на сенсорных устройствах |
| Режим ходьбы | 1 |
| Открыть / закрыть меню строительства | Кнопка «Строительство», B или 2 |
| Каркас / ящик / верстак | 3 / 4 / 5 или каталог |
| Установить / выбрать | Левая кнопка мыши / касание |
| Переместить выбранный объект | M, затем нажать на новое место |
| Повернуть на 90° | R |
| Удалить выбранный объект | Delete или кнопка |
| Отменить предпросмотр / снять выделение | Escape или правая кнопка мыши |
| Сохранить | Кнопка или Ctrl/Cmd + S |
| Восстановить последнее сохранение | «Загрузить» |

Игра занимает весь экран; кнопки и панели находятся поверх игрового поля. Каталог строительства по умолчанию закрыт и не изменяет размер поля при открытии. После выбора объекта каталог закрывается. Действия с объектом появляются при выделении или размещении. Escape закрывает открытый каталог или отменяет размещение.

После установки нового объекта можно ставить следующий того же типа. При перемещении старое положение остаётся занятым до подтверждения; отмена не меняет компоновку. Движение доступно во время строительства. На узких экранах вагон поворачивается вертикально, управление соответствует направлениям экрана.

## Параметры первого этапа

- Вагон: 12 × 3 × 2,5 м (48 × 12 × 10 вокселей).
- Сетка: 0,25 м. Все объекты на полу, повороты с шагом 90°.
- Персонаж: диаметр 0,5 м, высота 2 м; круг для проверки столкновений, скорость 1,75 м/с.
- Прямой проход шириной 0,5 м допускается геометрией; для удобного движения рекомендуется 0,75 м. Полная проверка связности проходов относится к будущим этапам.
- Фиксированный каркас: 1,5 × 1 × 2 м. Свободные сооружения: ящик 0,75 × 0,75 × 0,75 м и верстак 1 × 0,75 × 1 м.
- Геометрия хранится в вокселях и проверяется по трём осям; на первом этапе Z = 0. Произвольные размеры, потолочное крепление и внутреннее оборудование относятся ко второму этапу.
- Производство, трубы, движение поезда и мир на этом этапе отсутствуют.

## Сохранения

Кнопка «Сохранить» записывает всю компоновку, повороты и положение персонажа в `localStorage` этого браузера и адреса сайта. При следующем открытии последнее сохранение загружается автоматически. «Загрузить» отменяет изменения после сохранения. Экспорт и импорт JSON доступны в меню строительства. Импорт проверяет версию, габариты, идентификаторы, столкновения и позицию персонажа до замены текущего состояния. После импорта нужно нажать «Сохранить».

## Проверки

```sh
npm test
```

Тесты геометрии, столкновений, переноса, поворота и сохранений находятся в `tests/`. Игровая модель — `web/core.js`, интерфейс и отрисовка — `web/game.js`.
