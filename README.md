# TRAIL — Поезд-завод

Веб-прототип на JavaScript и Canvas 2D. Реализованы этапы 1–4: неподвижный вагон, персонаж со столкновениями, строительство, стеллажи с настраиваемыми полками, порты, трубопроводы и работающая очистка нефти. Без внешних зависимостей и сборки.

Игра: https://10-13.github.io/Trail/

## Запуск и проверки

```sh
npm run dev
npm test
```

Сервер открывается на `http://localhost:4173`. Нужны Python 3 и Node.js. Файлы из `web/` можно разместить на любом статическом хостинге. Используются ES-модули, поэтому исходники открываются через HTTP.

Модель проверяет `npm test`: геометрия, полки, соединения, производство, ресурсы и планировщик TPS. Для браузерных проверок при запущенном сервере:

```sh
python3 tests/browser_smoke.py
python3 tests/shelves_browser.py
python3 tests/stage3_browser.py
python3 tests/connections_browser.py
python3 tests/stage4_browser.py
python3 tests/fast_simulation_browser.py
python3 tests/ownership_browser.py
python3 tests/rack_overview_browser.py
python3 tests/rack_orientation_browser.py
```

Нужны Playwright, Pillow и Chromium по пути `/usr/bin/chromium`. Снимки сохраняются в `/workspace/shared`. Координаты действий на полке определяются по отрисованной сетке.

| --- | --- |
| Движение по вагону | WASD, стрелки; экранные кнопки на сенсорных устройствах |
| Открыть / закрыть выбор блоков | Tab или «Блоки» |
| Расставлять выбранный блок | Клики или удержание левой кнопки мыши / касания |
| Включить / выключить кисть удаления | Backspace или «Удаление» |
| Удалить кистью | Нажать на объект или провести по объектам |
| Выбрать объект | Клик, когда кисти выключены |
| Переместить выбранный объект | M, затем нажать на новое место; в редакторе также перетаскивание |
| Повернуть на 90° | Выбрать ось X / Y / Z, затем R или «Повернуть» |
| Открыть выбранный стеллаж | E или «Открыть стеллаж» |
| Выбрать полку для редактирования | Клик по полке в объёмном обзоре; также список «Полка» |
| Вернуться к объёмному выбору | «Обзор»; Escape из пустого плана |
| Переключить полку в плане | Список «Полка», PageUp / PageDown |
| Труба между полками | «Труба ↑» / «Труба ↓», затем клик по ячейке |
| Масштаб и перемещение вида | Колесо, + / − / «Вписать»; перетаскивание пустого места |
| Закрыть меню / убрать кисть / снять выбор | Escape или правая кнопка мыши |
| Вернуться из редактора в вагон | «В вагон» или Escape, когда меню и кисти выключены |
| Сохранить, в том числе из редактора | Ctrl/Cmd + S или кнопка |
| Восстановить последнее сохранение | «Загрузить» |

В вагоне размещаются **только стеллажи**. Ящики, верстаки, производственные блоки и трубы ставятся на их полках. Полки всегда параллельны полу; стеллаж можно поворачивать только вокруг вертикали. Оборудование внутри сохраняет повороты по трём осям.

Ходьба всегда доступна в вагоне, в том числе с кистями установки и удаления. Отдельного переключателя ходьбы и строительства нет. Tab открывает меню в текущем экране: стеллажи в вагоне, оборудование и трубы на полках. Выбор блока закрывает меню. Кисть остаётся активной после каждого размещения; Escape убирает её. Backspace включает удаление по клику и не удаляет объект до нажатия на него. В числовых полях Backspace сохраняет обычное редактирование текста; Shift+Tab позволяет переходить по полям.

Игра занимает всё окно; интерфейс находится поверх поля. При переносе исходное положение остаётся занятым до подтверждения. По одному месту с несколькими высотными объектами можно нажимать повторно для выбора следующего. Кнопка «Слой» ограничивает выбор полом или потолком; объекты другого слоя приглушены.

## Стеллажи и полки

Каркасы теперь работают как стеллажи. В вагоне через Tab выбираются длина, ширина, общая высота и крепление к полу или потолку. Новый стеллаж высотой от 2 м начинается с двух полок; более низкий — с одной. Внешний объём и проход под потолочным стеллажом по-прежнему проверяются с учётом роста персонажа 2 м.

При открытии стеллажа сначала появляется объёмный вид сбоку для выбора полки. Наведение плавно увеличивает её вертикальный просвет; при уходе курсора полка сжимается обратно. Основание раскрываемой полки и нижние полки остаются на месте, верхние приподнимаются. Блоки сохраняют свой размер. Клик по полке открывает один большой план сверху для редактирования; кнопка «Обзор» возвращает к выбору. На телефоне полка выбирается касанием. Стрелки вверх/вниз и Enter позволяют выбрать её клавиатурой. При настройке уменьшенного движения раскрытие происходит без анимации. Раскрытие — только визуальный приём: реальные высоты, блоки, трубы и ресурсы не изменяются. Tab из обзора открывает меню строительства на плане выбранной полки.

Редактор плана показывает один большой вид сверху выбранной полки. Три проекции и ручное управление срезами заменены списком полок. В строке инструментов видны полезная высота и число свободных ячеек. Список полок и PageUp / PageDown переключают этаж. Колесо и кнопки + / − меняют масштаб; перетаскивание пустого места или средней кнопкой двигает вид; «Вписать» возвращает его целиком.

Объёмный обзор и план полки всегда ориентированы по вагону: перед поезда слева, независимо от поворота стеллажа. Нижний край плана соответствует ближнему краю объёмного вида; верхний — дальнему. Блоки, трубы и порты отображаются в тех же местах относительно поезда, что и в вагоне; редактирование учитывает этот поворот.

**«Полки»** открывает разметку стеллажа. Для каждой полки задаётся полезная высота с шагом 0,25 м; сумма определяет общую высоту стеллажа и ограничена 2,5 м. Кнопка «＋ Полка» делит верхнюю полку, «− Верхняя» объединяет её с предыдущей. Толщину оснований прототип не вычитает. Изменение проверяется целиком: блоки должны помещаться, трубы и оборудование не могут пересекаться, содержимое не обрезается. Удалить полку с привязанными блоками можно после их переноса.

Tab выбирает блок или трубу. Новые блоки автоматически стоят на основании выбранной полки и должны укладываться в её высоту. Место задаётся кликом или кистью, размеры — в меню или свойствах. На разных полках допустим одинаковый план размещения. Выбранный блок можно перетащить, перенести через M с переключением полки или выбрать другую полку в свойствах. Идентификатор, содержимое и прогресс обработки сохраняются. R поворачивает блок вокруг вертикали; другую ось для блока или трубы можно выбрать в Tab → «Поворот по оси». Полки и весь стеллаж остаются горизонтальными.

Трубы рисуются на основании полки. **«Труба ↑» / «Труба ↓»** и клик создают физическую вертикальную колонну до соседней полки, проверяя все промежуточные ячейки. Редактор переключается на её конец: следующий клик продолжает горизонтальный маршрут. Стрелки на плане показывают выходы вверх и вниз. Удаление перехода убирает связанную вертикальную колонну целиком; заполненную колонну сначала нужно выбрать и нажать «Забрать содержимое перехода». Ответвления по-прежнему запрещены.

При изменении высот блоки с привязкой к полке перемещаются к её новому основанию; трубы сохраняют свои координаты. Изменение, которое вызовет пересечение, отклоняется. Связи после изменения разметки пересчитываются, ресурсы остаются в системе.

Существующие схемы v1–v5 загружаются без сдвига оборудования, труб и ресурсов: стеллаж без разметки получает одну полку на всю высоту. Старые приподнятые блоки остаются на прежних местах до их редактирования. При переносе или изменении размеров редактор ставит их на основание полки. Нельзя провести новое основание сквозь старый блок — сначала перемести его.

## Этап 3: порты, трубы и граф

У оборудования и свободных сооружений есть входы и выходы. По умолчанию — вход слева и выход справа, если смотреть на блок до его поворота. Цвет входа — голубой, выхода — жёлтый. Светлая рамка отмечает подключённый порт.

Выбери блок и раскрой «Порты». Там можно добавлять и удалять порты, менять вход на выход, выбирать одну из шести граней и задавать два смещения по этой грани с шагом 0,25 м. Грани и смещения заданы в локальных осях блока до поворота. При повороте и переносе блока, а также его каркаса порты перемещаются вместе с ним. Уменьшение блока, при котором порт оказался бы за границей, запрещено.

В меню Tab появился пункт «Трубы». Основной инструмент — «Маршрут кистью»: нажать у порта или на свободном конце трубы и провести путь. Пропущенные указателем клетки заполняются последовательным маршрутом по осям. Свободный конец всегда остаётся прямым; при продолжении прежний конец может стать поворотом. У порта маршрут также требует прямого участка.

Труба соединяет ровно две грани. Ответвления и тройники запрещены: попытка добавить третье направление отклоняется целиком, существующая линия сохраняется. Пересекающиеся линии нужно разнести по разным ячейкам или высоте. Соседние параллельные трубы не объединяются.

Для точного редактирования доступны прямой участок, поворот, вертикальный элемент и собственная пара открытых граней. Соединение возникает только при взаимно открытых гранях двух соседних ячеек, а с портом — если грань трубы обращена к нему. Направление передачи задаётся входом/выходом порта. Соприкасающиеся встречные выход и вход могут соединяться напрямую.

В редакторе для оборудования есть компактный выбор оси вращения: X — вдоль, Y — поперёк, Z — вертикаль. R или «Повернуть» выполняет четверть оборота вокруг выбранной оси. Это работает для кисти, выбранной трубы и оборудования. Стеллаж в вагоне поворачивается только вокруг вертикали, сохраняя горизонтальные полки. В редакторе оси локальны каркасу; в вагоне — вагону. Порты и внутренние трубы поворачиваются вместе с объектом; габариты, столкновения и крепление к потолку пересчитываются. Недопустимый поворот не меняет объект.

В редакторе открой Tab → «Соседние подключения». Порты соседних каркасов и свободные концы соседних труб показываются в списке и номерными маркерами на границах плана полки. Выбери подключение текущего каркаса и соседнее подключение, затем нажми «Проложить соединение». Труба пройдёт через свободные ячейки внутри каркасов и промежуток между ними, обходя оборудование, персонажа и другие трубы. Начало и конец такого соединения прямые. Если места нет, появляется причина отказа. Команда «Соединить два порта» в Tab позволяет выбрать два порта кликами, в том числе переключив полку между ними.

Внутри стеллажа трубы рисуются на плане выбранной полки; вертикальные переходы соединяют соседние полки. В вагоне нет кисти свободных труб. Между двумя стеллажами создаётся только соединение с привязкой к обоим концам. Низкое соединение блокирует проход; на высоте 2 м и выше под ним можно пройти.

Труба занимает ячейку 0,25 × 0,25 × 0,25 м. В одной мировой ячейке может быть только один элемент. Все внутренние трубы, в том числе созданные автопрокладкой, принадлежат стеллажу в его локальных координатах. Автопрокладка между портами одного стеллажа ограничена его объёмом. Между разными стеллажами внутренние участки записываются в соответствующие стеллажи, а участки в промежутке явно ссылаются на оба конца.

**Удаление стеллажа** удаляет его оборудование, все внутренние трубы и внешние соединения, привязанные к нему. Содержимое буферов и удаляемых труб автоматически возвращается в запас. В вагоне кисть удаления выбирает весь стеллаж даже при клике по видимой трубе внутри него. Перенос, поворот или изменение габаритов стеллажа разбирает его внешние соединения с возвратом содержимого, а внутренние трубы перемещаются вместе со стеллажом.

Компактный раздел «Связи» доступен в вагоне и в редакторе. Он показывает направленные пути от выходов к входам. Нажатие на строку подсвечивает соответствующие участки. После удаления трубы, перемещения/поворота аппарата или изменения порта граф полностью пересчитывается. Если путь разорван, прежняя связь и подсветка исчезают. Каждая труба имеет только два направления; автоматических ответвлений нет. Циклы не дублируют найденные связи.

Вместимость элемента — 4 единицы суммарно, включая смесь ресурсов. Ресурсы движутся дискретно и видны в трубах цветными геометрическими значками.

## Этап 4: производство

Нажми **«Пример» → «Пуск»**, чтобы открыть готовую цепочку в редакторе. На первой полке находятся основные аппараты, на второй — баки отходов; их соединяют вертикальные трубы. Пример использует 128 единиц нефти и пять соединений: основной маршрут и два отдельных выхода отходов. «Вернуть схему» восстанавливает компоновку, которая была открыта до примера, вместе с ресурсами; резерв хранится в текущей вкладке. Само открытие примера не перезаписывает браузерное сохранение. «Сохранить» и экспорт работают с текущей открытой схемой.

Свою линию можно собрать через Tab: бак, фильтр, центрифуга и трубы. У новых и перенесённых с предыдущих этапов схем есть конечный запас из 64 единиц нефти. Выбери бак или аппарат, укажи ресурс и нажми «Загрузить 4»: в буфер перейдёт до четырёх единиц из запаса. «Забрать всё» возвращает содержимое аппарата или трубы в запас. Запас доступен в компактном разделе рядом с кнопкой пуска.

| Аппарат | Рецепт | Время |
| --- | --- | --- |
| Фильтр | 4 нефти → 3 фильтрата + 1 шлама | 1,5 с |
| Центрифуга | 3 фильтрата → 2 чистой нефти + 1 осадка | 2,5 с |

Шлам и осадок требуют отдельных подключений и приёмных баков. Общая численность ресурсов сохраняется: полный цикл превращает 4 единицы сырья в 2 единицы чистой нефти и 2 единицы отходов. Это условная игровая технология.

У аппаратов входной и выходной буферы по 8 единиц; у бака по умолчанию 32 единицы общей вместимости. В свойствах бака вместимость можно менять от 1 до 256, сохраняя место для уже находящихся в нём ресурсов. Фильтры ресурсов на портах задаются в разделе «Порты», вместе с направлением входа/выхода. По умолчанию новые производственные аппараты уже разделяют сырьё, продукт и отходы. Оборудование можно выключить через свойства.

В обычном режиме симуляция выполняет один такт каждые 0,25 с (4 TPS), независимо от отрисовки. Кнопка **«10kGz»** запускает ускоренный режим с целью 10 000 тактов за реальную секунду. Индикатор **TPS** показывает число фактически выполненных тактов за последнюю секунду, а не заданную частоту. При нехватке производительности показание будет ниже цели. Логическая длительность такта остаётся 0,25 с: при 10 000 TPS игровое время идёт в 2500 раз быстрее. Пакет тактов ограничен 8 мс на кадр, обновление показателей — раз в 250 мс; ввод и строительство остаются доступны. Нажатие «Пауза» останавливает любой режим, «Пуск» возвращает обычные 4 TPS, повторное нажатие «10kGz» во время ускорения ставит паузу. Выбранная частота сохраняется вместе с состоянием; после возвращения из фоновой вкладки пропущенное время не догоняется. Кнопки «Пауза» и «Один такт» позволяют осмотреть каждый переход. Каждый аппарат выдаёт до одной единицы за такт, чередуя подходящие доступные выходы. Ресурс в трубе проходит максимум одну связь за такт; новые поступления не могут быть повторно выданы тем же тактом. Для заполненных ячеек используются места на начало такта, поэтому передача не зависит от порядка обхода графа. Пятого ресурса в ячейке не бывает.

Заполненный приёмник создаёт затор назад по линии. Разрыв соединения или неподходящий ресурс на порту удерживает содержимое на месте; восстановление пути возобновляет передачу. У аппарата видны рецепт, буферы, прогресс и причина ожидания; у трубы — содержимое и состояние приёмника. Удаление отдельного заполненного аппарата или трубы блокируется с объяснением: сначала забери содержимое. При удалении всего стеллажа ресурсы его содержимого и соединений возвращаются в запас автоматически.

Оформление следует минимализму shapez.io: простые формы аппаратов, пять цветов и форм ресурсов, тонкие полоски заполнения и прогресса. Игровое поле остаётся на весь экран, каркас редактируется на отдельном экране.

## Параметры и сохранения

- Вагон: 12 × 3 × 2,5 м, или 48 × 12 × 10 вокселей.
- Воксель: 0,25 м; геометрия и столкновения учитывают три оси.
- Персонаж: диаметр 0,5 м, высота 2 м, скорость 1,75 м/с.
- Геометрический прямой проход: от 0,5 м; рекомендуемая ширина — 0,75 м. Проверка связности всех проходов не реализована.
- Ящики и верстаки также размещаются внутри стеллажей.

Кнопка «Сохранить» записывает компоновку и положение персонажа в `localStorage` текущего адреса сайта. Сохраняются габариты и крепление каркасов, локальные координаты оборудования, повороты и идентификаторы. Формат v6 сохраняет владельцев межстеллажных соединений, разметку полок и привязки блоков к ним, порты, фильтры ресурсов, все мировые и локальные трубы, запас, буферы, ресурсы с приёмниками в трубах, незавершённую обработку, время и паузу. Он автоматически загружает сохранения предыдущих этапов (v1–v5); ключ браузерного хранилища оставлен прежним. После перезагрузки восстанавливается последнее сохранение. Объёмные повороты дополнительно сохраняют ориентацию из 24 возможных положений. Старые трубы с нулём, одной или более чем двумя гранями приводятся к паре граней; при этом показывается уведомление с просьбой проверить соединения. Свободные объекты старых схем получают стеллаж по своему габариту; запасы и адреса портов переносятся. Старые мировые трубы внутри стеллажей принимаются в их состав, межстеллажные соединения получают владельцев. Бесхозные внешние трубы разбираются с возвратом ресурсов. Наклонённые старые стеллажи выравниваются с пересчётом локальных координат, сохраняя мировое положение оборудования и труб.

Импорт/экспорт JSON доступны в меню строительства. Импорт полностью проверяет данные до замены состояния, включая вложенные объёмы. После импорта нужно сохранить компоновку.

## Устройство кода и интерфейс

- `web/geometry.js` — определения и общая объёмная геометрия.
- `web/core.js` — состояние, проверки строительных изменений, столкновения, сохранения и миграция.
- `web/logistics.js` — грани, порты, мировые координаты труб и направленный граф.
- `web/simulation-runner.js` — планировщик 4 / 10 000 TPS, ограничение времени пакета и измерение фактической частоты.
- `web/simulation.js` — фиксированный такт, рецепты, ограниченный транспорт, баланс ресурсов и валидация.
- `web/production-ui.js` — общие индикаторы, управление симуляцией, буферы и геометрические значки.
- `web/production-demo.js` — обратимый пример цепочки с конечным запасом.
- `web/network-ui.js` — общие контролы портов и труб, отладочные связи и отрисовка.
- `web/game.js` — сцена вагона, управление и строительство.
- `web/rack-overview.js` — объёмный выбор полки, устойчивое наведение, плавное раскрытие и доступные кнопки выбора.
- `web/frame-editor.js` — большой план полки, кисти, переходы, масштаб и разметка.
- `web/ownership.js` — миграция свободных объектов, выравнивание старых стеллажей и привязка старых труб.
- `web/shelves.js` — разбиение по высоте, размещение блоков на полках и свободное место.
- `web/ui.js` — общие нативные поля ввода и DOM-примитивы без зависимости от игрового состояния.

Ориентир интерфейса — [WPGBoard](https://github.com/10-13/WPGBoard), в частности его `work/atlas/style.css` и подход к компонентам UI: компактная моноширинная типографика, ритм 16 px, плоские панели, нативная валидация ввода и отделение представлений от модели. Реализация TRAIL самостоятельная.

Следующий этап — удобство строительства: отмена и повтор, копирование каркасов и улучшение подсветки. Движение поезда и большой мир пока не реализованы.
